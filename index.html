Research

DreamMix: Decoupling Object Attributes for Enhanced Editability in Customized Image Inpainting

IJCV 2026 · CCF-A First Author 2024

Decouples object identity from textual attributes so that a customized object can be inserted into a scene and then edited by text — without losing its identity.

  • Introduced an Attribute Decoupling Mechanism, a Textual Attribute Substitution module, and a disentangled local–global inpainting framework.
  • Reaches CLIP-T 0.289 on SDXL and 0.290 on FLUX, adapting from only 4–6 reference images.
  • Open-source project with 100+ GitHub stars.

FineRS++: Multi-Hypothesis Reasoning and Segmentation of Small Objects in High-Resolution Images

TPAMI · Under Review Student First Author 2026

A Qwen2.5-VL-based global–local perception framework for reasoning about and segmenting small objects in very high-resolution images.

  • Coarse-to-fine MLLM reinforcement learning (GSE + LPR) with a GRPO localization-aware backtracking reward.
  • Built a dedicated high-resolution small-object annotation dataset; on FINERS-4k reaches gIoU 55.1, cIoU 46.5, MVQA 83.3%, OVQA 56.7%.
